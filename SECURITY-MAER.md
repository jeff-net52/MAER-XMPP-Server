# Sécurité de MAER XMPP Server

Ne publiez pas de vulnérabilité exploitable, d’identifiant, de jeton, de clé,
de certificat privé, de sauvegarde ou de configuration de production dans une
issue publique.

Les clients MAER doivent utiliser le canal de support privé défini dans leur
contrat commercial. Les coordonnées de signalement public propres à MAER
doivent être ajoutées avant l’ouverture commerciale du service.

Pour une vulnérabilité du cœur ejabberd non spécifique au fork, suivez aussi la
procédure de sécurité amont décrite dans [`SECURITY.md`](SECURITY.md). Ne
divulguez pas le problème publiquement avant coordination et correctif.

Chaque incident doit conserver une chronologie, limiter l’accès aux données,
révoquer les secrets compromis, vérifier les autres organisations et produire
les notifications contractuelles ou réglementaires applicables.
